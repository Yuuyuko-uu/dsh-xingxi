# 星汐 · dsh-xingxi

把整理好的记忆档案连成一张**看得见的星图**。

记忆卡的一节是一颗星，日记的一天也是一颗星；同一章的星连成星座，同一段时间的星连成星带。
点一颗星，看见它背后的原话。

---

## 它解决什么

上下文一压缩，AI 就不知道自己是谁了。主流的解法是「存更多、检索更准」——
但存得好和**想得起来**是两件事。

星汐不做存取，它做**看得见**：让「她是谁」「我们怎么走到今天的」这些事，
不是躺在一个 143KB 的 markdown 里等着被检索，而是**有一张图**，你能看见结构、能顺着线走。

> 它不替代任何一个记忆插件。遗忘、权重、每轮注入，是别的插件在做的事；
> 星汐只负责把**已经整理好的**档案摊开给你看。

## 长什么样

**一团散开的星云。**

- 中央核心星代表第一章的核心记忆
- 记忆星沿用档案中的章节与条目；颜色与大小区分星点层级
- 日记按日期排成星带；有明确事件日期的记忆卡也会落到对应时间位置
- 星点位置固定（每次打开都一样），章节关系线可用右上角开关

默认能看见完整星图；聚焦一颗星时，相关的章节线与关联线会更亮。
时间线可拖动或播放：有明确日期的记忆按真实日期出现；没有明确日期的记忆按章节顺序渐显。

- **时间线**：拖动或播放，观察记忆和日记逐步展开
- **搜索**：输入「周三」「外卖」，命中的星会亮起来并圈住
- **图例**：点一章，只亮那一团

拖拽转动、滚轮缩放、点星星看原话。**只读**，不会改你的档案一个字。

## 装上

```bash
dsh plugin add github:Yuuyuko-uu/dsh-xingxi
```

或者：

```bash
dsh plugin add <这个仓库的绝对路径>
```

装完重开，左边侧栏多一个星形图标（跟「插件」「定时任务」并排），点开就是星图。

## 告诉它档案在哪

它要两份 markdown：

| | 长什么样 | 说明 |
|---|---|---|
| **记忆卡** | `## 一、我是谁` → `### 1.1 性格特征` → 正文 | 按主题分章；星图上就是八个星座 |
| **日记** | `## 2026-08` → `- **08-16**：那天发生了什么` | 按天一条；星图上就是那条星带 |

两种办法：

1. 在 DSH 的设置里找到「星汐」，填两个路径；
2. 或者把两个文件放进 `~/.dsh/startide/`，文件名里带「记忆卡」「日记」就会自己认出来。

> 没有这两份文件也能装，星图是空的 —— 它会告诉你「还没指定档案」。
> 这两份文件怎么攒出来，是另一件事（见下文「档案从哪来」）。

## 档案从哪来

星汐**不负责**整理档案，它只管把档案摊开。攒档案的流程是：

```
原始存档 → 按天切段 → 提炼 → 合并成笔记 → 并进记忆卡 + 日记
```

每条都问一句「过了一个星期再看，这条还有用吗」——答不上「有用」的不收。
细节各家不同，这套流程的完整做法在 `docs/` 里（还没整理好，先看仓库 issue）。

## 已知边界

- **只读**。这一版没有编辑、没有删除、没有遗忘曲线。
- 相似度用的是「两字一组」的重叠率，中文够用，但不懂语义。
- 星的数量到几千颗会开始卡（两两算斥力是 O(n²)）。
- 只认上面那两种 markdown 结构，别的不画（会说没读到）。
