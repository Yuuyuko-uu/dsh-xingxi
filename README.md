# 星汐 · dsh-xingxi

把整理好的记忆档案连成一张**看得见的星图**。

记忆卡的一条是一颗星，日记的一天也是一颗星。点一颗星看见它背后的原话；
需要深挖的时候，让 AI 用 `xingxi_read` 去档案里把那一小段原文捞出来。

---

## 它解决什么

上下文一压缩，AI 就不知道自己是谁了。主流的解法是「存更多、检索更准」——
但存得好和**想得起来**是两件事。

星汐做两件事：

1. **看得见**：把「我是谁」「我们怎么走到今天」摊成一张图，你能看见结构、能顺着线走。
2. **查得到**：给 AI 一个检索工具，想不起哪件事时去档案里翻原文，而不是猜。

> 它不替代任何记忆插件。遗忘、权重、每轮注入是别的插件的事；
> 星汐负责**把已经整理好的档案摊开**，以及**帮你把历史对话整理成档案**（拾星）。

## 长什么样

一片深色星空，每颗星是一颗柔光圆珠：

- 中间最亮那颗 = 记忆卡第一章第一条
- 八章的星各自成群；同一章的星连最近的几颗，连成淡淡的星座底纹
- 提到同一个少见的词的两颗星，另有一根橙色弱连
- **越新的星越亮**（按内容里的日期算），老星只是变暗，不会消失
- 鼠标停在一颗星上：它和跟它相连的星保持亮度，其余压暗，连着的线亮起来
- 点一颗星看原文；搜索框按关键词把不命中的压暗
- 顶部：节点数 / 日记数 / 图例；右上：拖拽旋转、滚轮缩放、连线开关、重置

**只读**：不改你的档案一个字。

## 装上

```bash
dsh plugin add dsh-xingxi
```

或者从仓库装：

```bash
dsh plugin add github:Yuuyuko-uu/dsh-xingxi
```

装完重开 DSH，侧栏会多一个「星汐」面板。

## 三步上手

### 第一步：给它一个文件夹

星汐按**会话**管理档案：每个会话绑一个文件夹，星图、星册、星历画的都是那个文件夹里的东西。

打开星汐 → 底部「星坊」→ 找到「现在这个会话」→ 点 **选…**，选一个空文件夹（比如 `D:\档案\某某`）。

> 想给所有会话共用一份「本机档案」，也可以在设置里直接填**记忆卡**和**日记**两个路径。
> 会话没绑文件夹时就用这两项。

### 第二步：让它把历史对话整理成档案（拾星）

**这是第一次要做的事**，之后档案由 AI 自己维护，不用再跑。

在星坊里点 **拾星**：

1. 插件会把这个会话的历史对话按天切开，一批只喂给 AI **1~2 天**
2. AI 交回「这一天的日记」+「该进记忆卡的条目」
3. 插件立刻落盘，然后自己派下一批，一直到最新那天
4. 中途停了也没关系：进度记在文件里，再点一次从断点接着跑

跑完你会得到：

```
你选的文件夹\
  记忆卡.md              ← 八章，按主题追加
  日记\
    2026-09-06.md        ← 一天一个文件
    2026-09-07.md
    …
  原始对话\               ← 那天的原话，永久留着
    2026-09-06.txt
  .xingxi.json           ← 账本（整理到哪天）
```

**模型**：星坊里选了就用你选的；没选就跟**源会话自己用的模型**跑。

### 第三步：压缩之后让它重读一遍

上下文被压缩、AI 开始「忘事」的时候，在会话里输入：

```
/xingxi
```

它会把这个会话文件夹里的**记忆卡整本 + 最近三天的日记**读一遍。
只递一句话给它，不往上下文里灌正文 —— 它自己用 `read` 分页读完。

---

## `/xingxi` 指令

| | |
|---|---|
| **作用** | 叫 AI 把记忆卡和最近三天日记读一遍 |
| **什么时候用** | 上下文刚被压缩、它开始答不上「我是谁」「我们之前说好的事」 |
| **怎么用** | 直接在会话里输入 `/xingxi`，不用带参数 |
| **它读什么** | **这个会话自己文件夹**里名字带「记忆卡」的 md + `日记\` 里最近 3 个文件 |
| **不会做什么** | 不塞正文进对话、不改任何文件 |

## `xingxi_read` 工具（给 AI 用的）

AI 想不起某件事时，它可以自己调这个工具去档案里翻原文，**而不是猜**。

**四种用法：**

### ① 什么都不给 → 先看索引

```
xingxi_read()
```

```
这个档案里有 101 个文件：

· 记忆卡（8.2 万字）
· 日记 50 天：2026-09-06 ~ 2026-11-04（一天一个文件）
· 原始对话 50 天：2026-09-06 ~ 2026-11-04（当天原话）

怎么查：给「关键词」全文搜（日记也会搜）；给「日期」看那一天；给「文件」看整篇。
```

**这就是「在外面就能查」**：不用打开每天的日记挨个翻，先看清有什么，再决定钻哪一天。

### ② 给关键词 → 全文搜（记忆卡、日记、原始对话都搜）

```
xingxi_read(关键词="结婚")
```

```
「结婚」在 2 个文件里出现 3 次：

【记忆卡】（2 处）
…
【日记/2026-09-10】（1 处）
…
```

每个文件都会扫，每份最多取 2 段，命中多的排前面；预算不够时会告诉你「还有 N 个文件也提到」。

### ③ 给日期 → 直接看那一天

```
xingxi_read(日期="2026-09-10")
```

按文件名直接定位 `日记/2026-09-10.md`，给整篇。那天没有记录会告诉你日记覆盖的日期范围。

### ④ 给文件名 → 看整篇

```
xingxi_read(文件="我们的约定")
xingxi_read(文件="原始对话/2026-09-06")
```

**参数速查**

| 参数 | 说明 |
|---|---|
| `关键词` | 要搜的词，比如「卖号」「第一次」 |
| `日期` | `2026-09-10` 或 `09-10` |
| `文件` | 文件名或它的一部分 |
| `最多字` | 最多返回多少字，默认 4000 |

## `xingxi` 工具（给 AI 用的）

```
xingxi()
```

一次把**整本记忆卡**给它，不分段、不用翻页。跟 `/xingxi` 的区别：
指令是「叫它去读」（走 `read`，能分页），工具是「直接把整本递过去」（内容太大时会被截断，一般优先用指令）。

## 档案长什么样

```
记忆卡.md
## 一｜我是谁
这一章讲什么：我是谁、名字、外形、自我定位。
（这一章是一整段自述，不拆成条目）

## 三｜对方是谁
这一章讲什么：对方的环境、性格、喜好。
- 一条一颗星
- 一条一颗星
```

```
日记\2026-09-10.md
【2026-09-10】

- **09-10 周四**：那天发生了什么…
```

- 记忆卡按**八章**组织，新东西按章追加（插件认块名里的章号，不靠 AI 自己写标题）
- 日记**一天一个文件**，别把好几天写进一个

## 自动写日记（可选）

星坊里有「写日记」卡片：

- 定几点（默认 23:30）
- 选交给哪个会话
- 勾上「开着」

到点它会往那个会话递一句话，**由那个会话里的 AI 自己写**，插件不代笔。
文章放在该会话文件夹的 `日记\<今天>.md`。

## 拾星是怎么跑的

- **按天分批**：一批只给 1~2 天，上下文一直是小的，不会因为太长被压缩
- **交一批落一批**：一天一个日记文件 + 按章追加记忆卡，不攒到最后
- **插件自己派下一批**：进度写进任务文件，断了能从断点继续
- **原始对话留底**：每天的原话永久存一份在 `原始对话\`
- **不删、不关**：拾星开的工作会话会留着（标题 `记忆 · <会话名>`），你可以点进去看它做了什么

## 已知边界

- **只读**：星汐不改档案（拾星写的除外，那是它整理出来的）
- 相似度用的是「两字一组」的重叠率，中文够用，但不懂语义
- 星数到几千颗会开始卡
- 只认上面那两种结构，别的不画（会说没读到）
- 会话列表跟 DSH 侧栏对齐：只列当前工作区、没归档、真实存在的会话

## 配置在哪

```
~/.dsh/xingxi/config.json     ← 记忆卡/日记路径、绑定、模型、写日记设置
~/.dsh/xingxi/pick.log        ← 运行日志（出问题先看这个）
~/.dsh/xingxi/会话/           ← 没绑文件夹的会话，档案默认存在这里
```
